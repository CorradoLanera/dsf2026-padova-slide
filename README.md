# Sanità digitale sicura e sostenibile

Slide dell'intervento di Corrado Lanera al Digital Security Festival 2026, Padova, 4 novembre 2026.

- Slide: <https://corradolanera.github.io/dsf2026-padova-slide/> (tasto `M` per il menu).
- Link breve: <https://bit.ly/sanita-digitale-2026>. Con le note del relatore: tasto `S`.
- Sorgente: `slide.qmd` (Quarto revealjs), con `slide.scss`, `simboli.html`, `rotella.html` e le immagini in `img/`.
- `index.html` è il render, un file unico che funziona anche offline: `quarto render slide.qmd`, poi rinominato.

Testi, immagini e slide preparati con il supporto di strumenti di intelligenza artificiale generativa. Contenuti, scelte e verifiche sono dell'autore.
